# Qiskit_Learning
# Learning quantum computing
Several codes to learn - basic entanglement, superposition,teleportation, error correction using qiskit


# Entanglement: Linking qubits together (qc.cx).
# Superdense Coding & Teleportation: Moving quantum information.
# Phase Manipulation: Changing angles (qc.cz, qc.ry) and breaking classical limits (CHSH Game).
# Quantum Interference: Destroying the 0 wave to get a 1 (Deutsch-Jozsa).
# Quantum Security: Using basis switching to spot an eavesdropper (BB84)
